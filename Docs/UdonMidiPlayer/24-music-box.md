# 八音盒

日期：2026-11-04。作用范围：作者工程主场景 `Assets/Scenes/VRCDefaultWorldScene.unity`。正式收录、PC VRChat 客户端和维护者验收仍待完成；不将 Editor 检查当作客户端验收。

## 身份与操作

- 显示名：八音盒 / Music box / オルゴール；稳定目标7，模型8。停用目标6／模型7保留原身份。
- 乐器复选列表、文件原音色／音轨映射、硬件MIDI目标和MIDI学习均提供入口。GM Program10优先此音源；其余Program在原马林巴候选后追加八音盒。
- 声音保留 MIDI0～127；128个音高沿音筒轴向排列；88个实体梳齿覆盖 A0–C8（21～108），沿同一音高轴与滚动音符对齐。
- MIDI文件、现有硬件MIDI输入、PC座位键盘和VR触碰共用原播放器链路；设备实测状态见验证记录。

## 音源

录音作者 **rbnuser**，来源 [MusicalBoxSingleNotes，Freesound pack19724](https://freesound.org/people/rbnuser/packs/19724/)，**CC0 1.0**。12个实录根音为 MIDI74、79、81、84、86、93、95、96、98、100、102、103。原作者记录为 iPad 收录八音盒后用 Audacity 裁剪。

本次获取的是每条声音的 **HQ MP3预览**，没有将它标为无损原录音。许可证据为各声音页面，原HTML、MP3和SHA256保留在 `Downloads/MusicBox`。正式资源在 `Assets/UdonMidiPlayer/Audio/MusicBox`，包含CC0法律原文、署名及机器清单。

`node Tools/prepare_music_box.cjs` 可重建采样：Hann窗DFT在标注音高附近测量稳定基频，按测量值校音，转为48kHz单声道Vorbis q5，保留相对电平，仅作2ms音头／12ms尾部淡化。附加根音21、33、45、57、69、108为派生变调，**低音区不是实录**，音色会比本体低音更柔和、尾音更长。原始来源固定为声音ID、取得日期和SHA256；动态页面不是固定源版本，复现需核对已存音频哈希。

运行复用 `PianoBankAsset → MidiDataBaker → PianoBankData`、20ms能量表与共享声音池，每逻辑音占1条物理源，总数仍64。单力度层，沿用单层力度幂增益，固定bank gain0.7；没有逐音归一化。无循环／无额外奏法，NoteOff和CC64沿用采样bank的释放语义，最大释放包络1800ms，自然采样结束会先行结束声音。

## 模型与表现

桌上式木盒，盒体约50×22×13cm，含外置手柄约53cm宽。保留黄铜框、88个金属梳齿、音筒及手柄，去掉音筒表面的固定凸钉，罩上带倒角的透明防尘罩，侧边开缺口让手柄穿出。木盒放在独立的77cm圆桌上；原琴腿取消，长凳改为独立圆凳，保留PC键盘座位。美术源入口见 `ArtSource/MusicBox/README.md`；生成器在 `MidiMusicBoxBuilder.BuildModel`，导入／合并网格位于 `Assets/UdonMidiPlayer/Meshes/MusicBox`。原项目马林巴是表现参考，未引入第三方模型。

文件音符从光滑音筒后方越过顶部，绕到前下方的梳齿尖端。滚动角度按真实尖端坐标烘焙，音筒按同一角速度旋转。音符前端到达尖端时，发声、120ms短闪、光尘及拨片阻尼振动使用同一个MIDI起音时间。真实设备的输出延迟另行验收。筒面和音符内侧共用30.1 mm半径，64段筒面在世界比例下与圆弧偏差不超过0.04 mm；音符厚度向外约1.4 mm，最长约8 mm，倒角处仍贴合。88个拨片尖端按同一半径定位。暂停冻结，定位、停止和切歌沿用已有时钟与视觉状态清理。透明罩和外露手柄保留。

保留马林巴的曲目确定性色调、水晶音符和轻量粒子。仅八音盒使用曲面轨道；28个音符槽、2组光尘和2组符号粒子。光尘随起音在梳齿接触点短促迸开，偶尔浮起同色音符符号，两层均朝前上方扩散以避开音筒遮挡。无逐音灯。超过可见容量的音符仅省略画面，声音不受影响。

## 维护和兼容

三角钢琴被勾选时，八音盒随其摆到键盘后方平台上，并隐藏独立圆桌和圆凳；关闭三角钢琴或切换数码钢琴后，恢复原单乐器／合奏位置及桌凳。整体移动保留盒体、音符、效果、触碰区域和音源的一致位置。摆放由 Facade 的同一乐器选择入口刷新，初始状态与远端快照也沿用该入口；桌子碰撞保持关闭。

该摆放变更通过 Unity / UdonSharp 编译及 167 项 Editor/ClientSim backing Udon 检查，其中新增琴上摆放、桌凳显隐、数码钢琴回退和关闭三角钢琴后的原位恢复检查。渲染预览为 `Captures/MusicBox/Grand-Piano-Placement.png`；检查后恢复原 Edit Mode 状态，未进行真实 VRChat 客户端测试。

先准备采样，再在主场景、非Play Mode运行 `Tools > Music MIDI Player > Add or Update Music Box`。首次创建新资产，后续保留bank／mesh GUID和已存引用；现有未保存场景先保存副本到 `RecoveryBackups/MusicBox-20261104`。只更新外观时可用 `Tools > Music MIDI Player > Apply Tabletop Music Box`，不重烘焙音源或路由。不自动Apply实例覆盖，不更新分发Prefab、独立练习或发布白名单。

八音盒初版规则为 `selected-gm-v9-music-box`，并行的文件鼓组映射工作随后扩展为当前 `selected-gm-v10-file-drums`：有效mask191、跳过bit6；12组7目标排序。文件映射字符8表示目标7＋1，7继续拒绝；并行工作新增字符9（文件专用鼓组目标8），不占旋律启用位。实时起音kind10，快照目标＋1扩至20～23位，原音符身份位8～19保持。旧有效文件映射及本地设备设置可以读取，新增目标需要新版客户端；catalogHash包含新规则与音源，混合版本应按原哈希机制拒绝。多人交接／晚加入尚未做真实双客户端测试。
